# 🎉 EventEase – Android Event Management App

**EventEase** is an Android-based event management application developed using Java and XML in Android Studio. The application provides users with a convenient platform to explore event-related products and services, browse different event categories, and manage their selected items.

The project focuses on simplifying event planning through an organized interface and Firebase-powered backend services.

## ✨ Features

- **User Authentication:** Secure user registration and login using Firebase Authentication.
- **Event Categories:** Browse different event categories, including:
  - Wedding
  - Bridal Shower
  - Birthday
  - Mehendi
  - Puja
  - Reception
- **Product Browsing:** Explore event-related products such as sarees, sherwani combos, cakes, and flower bouquets.
- **Cart Management:** Add and manage selected items in the cart.
- **Booking Management:** Store and manage booking-related information using Firebase Realtime Database.
- **User Profile:** Access the profile section through the bottom navigation.
- **User-Friendly Interface:** Simple and intuitive UI designed to make event planning easier.

## 🛠️ Technologies Used

| Technology | Purpose |

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Android Studio
- Android SDK
- JDK
- Firebase account

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/minhazchyz/EventEase.git
   ```

2. Open the project in Android Studio.

3. Configure Firebase:
   - Create a Firebase project.
   - Register your Android application in Firebase.
   - Add the `google-services.json` file to the app directory.
   - Enable Firebase Authentication and Realtime Database.

4. Sync the Gradle files.

5. Build and run the application using an Android emulator or a physical Android device.

## 🎯 Project Objective

The main objective of EventEase is to provide a convenient and organized way for users to explore event-related products and manage their event bookings through a mobile application.

This project also provided practical experience in Android application development, Firebase integration, user authentication, database management, and mobile UI design.
