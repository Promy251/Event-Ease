🎉 EventEase -- Android Event Management App
EventEase is an Android-based event management application developed
using Java and XML in Android Studio. It provides users with a
convenient way to explore event-related products, browse different event
categories, and manage selected items.
✨ Features
- User Authentication: User registration and login using Firebase
  Authentication.
- Event Categories: Browse different categories, including:
  - Wedding
  - Bridal Shower
  - Birthday
  - Mehendi
  - Puja
  - Reception
- Product Browsing: Explore event-related products such as sarees,
  sherwani combos, cakes, and flower bouquets.
- Cart: Manage selected items.
- Booking Management: Store booking-related information using
  Firebase Realtime Database.
- User Profile: Access the profile section.
- Bottom Navigation: Navigate between Home, Profile, and Cart.

🚀 Getting Started
Prerequisites
- Android Studio
- Android SDK
- JDK
- A Firebase project
Installation
1. Clone this repository:
   git clone https://github.com/minhazchyz/EventEase.git
2. Open the cloned project in Android Studio.
3. Configure Firebase for the application:
   - Create a project in the Firebase Console.
   - Register the Android app using the package name configured in
     the project.
   - Add the google-services.json file to the app module directory.
   - Enable Firebase Authentication and Realtime Database.
4. Sync the Gradle files.
5. Build and run the application on an Android emulator or a physical
   device.
🎯 Project Objective
The objective of EventEase is to make event planning more convenient by
bringing event-related products and booking features together in one
mobile application. Developing this project provided practical
experience with Android development, Firebase integration,
authentication, database operations, and mobile user interface design.
